Tracks financial transactions and accounts for individuals and small businesses with a simple, easy-to-use interface.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/LedgerStone.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

LedgerStone is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
